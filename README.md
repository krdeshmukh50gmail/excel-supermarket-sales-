# 🛒 Supermarket Sales Data Analysis — Excel

A beginner-friendly **Supermarket Sales Data Analysis project built in Microsoft Excel** to analyze sales, profitability, category performance, city performance, product performance, and monthly trends.

The project demonstrates practical Excel skills including **data cleaning, aggregation, KPI creation, trend analysis, visualization, and dashboard design**.

## 🗃️ Raw Data

The **Raw Data** sheet contains **300 synthetic supermarket sales transactions** used for analysis.

The dataset is organized into structured columns that support sales, profit, quantity, category, city, product, and time-based analysis.

### Data Preparation

The raw data was organized and prepared for analysis using Excel techniques such as:

* Data cleaning
* Data formatting
* Removing inconsistencies
* Organizing transaction-level records
* Preparing fields for aggregation and visualization
